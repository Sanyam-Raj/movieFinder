# Movie Finder (movie-rec)

A React-based movie recommendation application designed to help users explore and discover movies tailored to their preferences. The application leverages modern web development tools and libraries to provide a seamless and interactive user experience.

## Features

- **Movie Recommendations**: Get movie suggestions based on user-defined criteria.
- **Responsive Design**: Styled using TailwindCSS for a clean and mobile-friendly interface.
- **Interactive UI**: Built with React and React Router DOM for dynamic and fast navigation.
- **Iconography**: Includes React Icons for visually appealing elements.
- **API Integration**: Uses Axios for fetching data from external APIs.

## Tech Stack

- **Frontend**: React, React Router DOM, TailwindCSS
- **Build Tool**: Vite
- **Language**: JavaScript
- **Linting**: ESLint

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Sanyam-Raj/movieFinder.git
   cd movieFinder
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to the local development server (usually `http://localhost:3000`).

## Scripts

- `npm run dev`: Start the development server.
- `npm run build`: Build the application for production.
- `npm run lint`: Lint the codebase using ESLint.
- `npm run preview`: Preview the production build.
